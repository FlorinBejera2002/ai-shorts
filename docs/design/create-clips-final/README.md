# Create clips — drafturi provizorii

Data: **23 octombrie 2026**. Acest folder conține **trei imagini inițiale**, generate cu ImageGen, neaprobate și neimplementate. Sunt drafturi provizorii de explorare, **nu ținte finale de implementare**. Datele și materialele ilustrate sunt demonstrative; nu au fost modificate date reale.

Utilizatorul a respins densitatea mare de text, chatul AI lat din dreapta și formularul îngust care lăsa o parte mare a spațiului nefolosit. Următorul pas este explorarea a **încă cinci modele desktop**, urmată de alegerea utilizatorului, înainte de continuarea întregului flux.

Modelele noi vor fi prezentate în [Create clips — modele de layout](../create-clips-models/README.md). Planul inițial de 32 de perechi desktop/mobil pentru fluxul complet este amânat până la această selecție; cele 64 de imagini nu sunt un set produs în acest moment.

## Cerințe pentru explorarea următoare

- Folosirea întregului spațiu de lucru, cu aliniere și proporții clare; fără formular îngust și jumătate de pagină goală.
- Text puțin și controale esențiale ușor de găsit, în stilul minimal Sneep Cut.
- Ghidarea AI apare într-un câmp mic și compact, fără un panou lat de chat în dreapta.
- Fără buton sau legătură **Write script** în conținutul principal. **Scripts rămâne în sidebar-ul global**.
- Se alege mai întâi un model desktop; apoi se extinde direcția la celelalte stări și la mobil, păstrând funcționalitatea reală și drafturile.

Sursele vizuale rămân [New post aprobat](../assets/new-post-approved-2026-10-22.png) și [ghidul Sneep Cut](../publishing-design.md). Tokenurile md/sm și cadrul persistent al dashboard-ului se păstrează. Excepția autorizată pentru navigarea Story Builder rămâne geometria Gooey Nav de 10 px.

Imaginile statice nu verifică încărcarea, generarea, costurile, salvarea, navigarea sau accesibilitatea. Nu s-a modificat aplicația prin aceste drafturi.
