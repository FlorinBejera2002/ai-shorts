# Studio interface fonts

These unmodified WOFF2 subsets come from the installed Fontsource Variable 5.3.0
packages for Inter and Sora. Their SIL Open Font License files are included here.

`fonts.css` loads Latin and Latin Extended glyphs, including Romanian diacritics,
through Vite's hashed asset pipeline. Inter supports weights 100–900 and Sora
100–800. `font-display: swap` uses the existing system fallback only while a font
loads or if loading is unavailable; no external font service is required.
